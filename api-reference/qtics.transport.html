qtics.transport.fake module#

Fake transport for tests: records commands and replies with scripted answers.

class qtics.transport.fake.FakeTransport(answers: Dict[str, str | bytes | Callable[[str], str | bytes]] | None = None, default: str | bytes | Callable[[str], str | bytes] | None = None, address: str = 'fake', terminator: str = '\n')[source]#

Bases: Transport

In-memory transport.

Every written command is appended to written. If the command is a key of answers its answer is queued for reading: strings are returned by read(), bytes by read_raw(), callables are called with the command. Queries (commands containing “?”) without a scripted answer get default (if not None); other commands get no answer.
