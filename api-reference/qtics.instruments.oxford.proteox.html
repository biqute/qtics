Bases: Instrument

Synchronous Proteox driver.

Wraps AsyncProteox, which runs on an event loop in a daemon thread. The dynamic get_<KEY>() and set_<KEY>(value) methods of AsyncProteox are available as blocking calls. Exceptions raised in the coroutines propagate to the caller.
