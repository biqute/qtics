BiQuTe cryogenic lab · Python

Drive the lab's instruments from Python.

One driver per instrument, one interface per instrument type: SI units, on/off as booleans, settings as properties and actions as methods.

from qtics import SMA100B, ZNB with ZNB("192.168.0.4") as vna, SMA100B("192.168.0.5") as src:    src.frequency = 5e9Hz    src.output = True    vna.set(f_start=4e9, f_stop=6e9, points=1001)    freqs, s21 = vna.snapshot()
