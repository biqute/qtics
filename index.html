Drive the lab’s instruments from Python#

Qtics collects the drivers of the BiQuTe cryogenic lab: one driver per instrument, one interface per instrument type. Units are SI, on/off states are booleans, settings are properties and actions are methods.

from qtics import SMA100B, ZNB

with ZNB("192.168.0.4") as vna, SMA100B("192.168.0.5") as source:
    source.frequency = 5e9  # Hz
    source.output = True
    vna.set(f_start=4e9, f_stop=6e9, points=1001)
    freqs, s21 = vna.snapshot()

Install it with pip install qtics (see Installation for the optional extras).
